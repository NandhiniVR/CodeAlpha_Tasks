# 🐍 CodeAlpha Tasks

Python projects completed as part of the CodeAlpha internship program. Covers machine learning, NLP, data analysis, and chatbot development.

## 📁 Projects

### 1. 🤖 Wardrobe Chatbot (`CodeAlpha_ChatBot/wardrobe-chatbot`)
A conversational chatbot that helps users plan outfits and manage their wardrobe.

### 2. 🌸 Iris Classification (`CodeAlpha_Iris Classification`)
Classic ML classification project using the Iris dataset. Trains a model to classify flower species based on petal/sepal measurements.

**Run:**
```bash
cd "CodeAlpha_Iris Classification"
pip install -r requirements.txt
python iris_classification.py
```

### 3. 🌍 Language Translator (`CodeAlpha_Translator`)
A Python-based language translation tool using NLP libraries.

**Run:**
```bash
cd CodeAlpha_Translator
pip install -r requirements.txt
python translator.py
```

### 4. 📊 Unemployment Analysis (`CodeAlpha_Unemployment_Analysis`)
Data analysis and visualization of unemployment trends using pandas and matplotlib.

**Run:**
```bash
cd CodeAlpha_Unemployment_Analysis
pip install -r requirements.txt
python analysis.py
```

## 🛠️ Tech Stack

- Python 3
- scikit-learn
- pandas
- matplotlib
- NLTK / translation libraries
