# Unemployment Trends Analysis

This project provides a Python script to clean, explore, and visualize unemployment rate data for India. It investigates the impact of the COVID‑19 pandemic (2020) on unemployment, identifies key patterns and seasonal trends, and generates insightful visualizations.

## Files
- `analysis.py`: Main script that loads the CSV, performs data cleaning, analysis, and saves plots.
- `requirements.txt`: Python dependencies.
- `unemployment_trends.png`: Example output plot (generated by the script).

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
```
The script will produce several PNG files in the `outputs/` folder.
